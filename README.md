# AI-Driven-Chatbot-INGRES-Project-
AI virtual assistant for INGRES that answers user queries, provides instant responses, and improves customer support using AI.
Project Overview

The AI-driven ChatBOT for INGRES is a virtual assistant designed to provide instant responses to user queries. It helps users access information about courses, admissions, fees, timings, and services. The chatbot improves communication, reduces manual support, and enhances the overall user experience.

Installation Steps

1. Download or clone the project from GitHub.


2. Install Python on your system.


3. Install required libraries using pip install.


4. Set up the Oracle database.


5. Configure the database connection.


6. Run the application.
